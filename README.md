# Retail Token-Efficiency Lab

A small standalone lab for learning AI-agent context and token efficiency from first principles.

This repository intentionally uses the public τ²-bench retail artifacts as **data**, while keeping the agent loop, context construction, tool execution, and measurements explicit and framework-free.

The first experiment is V0: full policy + all tool schemas + full raw history on every model call. Later versions should be added only when a measured failure or inefficiency motivates them.
